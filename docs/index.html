Why LaraViz

Everything your app is doing,
made visible

Stop grepping through files to understand your own codebase. LaraViz surfaces the structure and relationships that matter.

🗄️

Database Schema

Tables, columns, indexes, and foreign key edges — rendered as a live relationship graph. Works with MySQL, PostgreSQL, and SQLite.

🛣️

Route Explorer

Every route with its HTTP method, middleware stack, and controller. Grouped or flat view. Spot dead or duplicate routes instantly.

🧩

Eloquent Model Graph

Models and their relationships — HasMany, BelongsTo, ManyToMany — drawn as edges so you can trace data flow at a glance.

⚡

Events & Listeners

The full event fan-out in one view. Queued listeners are flagged, so you know which events are processed synchronously vs. async.

🔧

Service Providers

Container bindings, facades, and service providers — see exactly what is registered and where it comes from.

💼

Queue Jobs

Every job with its queue driver, queue name, retry config, and timeout. Understand your async workload at a glance.

🌊

App Flow

A visual walkthrough of the full request lifecycle, queue processing flow, and event dispatch chain.

🔒

Safe by Default

Blocked in production via a Gate. Config values with secret/key/token are automatically redacted. No data leaves your server.

Get Started

Up and running in
three commands

No Node.js required in production — pre-built assets are bundled with the package.

1

Install the package

Add LaraViz as a dev dependency via Composer.

composer require laraviz/laraviz --dev
2

Publish config & assets

The install command copies the config and pre-built frontend assets into your public directory.

php artisan laraviz:install
3

Open in your browser

Navigate to the LaraViz URL in your local app. The dashboard loads instantly — no build step needed.

http://your-app.test/laraviz
